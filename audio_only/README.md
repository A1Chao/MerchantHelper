# 行商助手 · 声控版 1.1.1（公开源码）

作者：**烟火**。新增独立的纯音频入口，沿用仓库根目录已有的音效、物品库和图标。
只监听系统回环音频，格数由玩家手动选择；不截屏、不读游戏内存、不注入、不模拟输入、不联网。

原有根目录入口与 `vision.py` 占位契约保持不变。私有 `_rt/`、视觉核心、打包管线、授权工具与密钥没有公开。
本次是源码更新，**不是新版 EXE 发布**；官方 EXE 的离线签名授权规则不变，下载仍通过 Releases。

## 运行（Windows / Python 3.11+）

在仓库根目录执行：

```powershell
python -m pip install -r audio_only/requirements.txt
python audio_only/main.py --list-devices
python audio_only/main.py
```

启动后点“开始监测”或按 F8；停止后不再处理新音频。F9/F10 只归档手动标注的样本，不会自动训练或改动识别模板。
音频设备异常后先停止、再重新开始，可受控重建已经失败的采集线程。

```powershell
python audio_only/main.py --diag --diag-seconds 6
python audio_only/main.py --audio-doctor --doctor-seconds 2
python audio_only/tests/run_all.py
```

`--audio-doctor` 可附加 `--doctor-tone` 播放短测试音；默认不会播放。
公开仓库不新增收款码图片，赞助对话框在缺图时显示提示，署名与原有界面功能保留。

## 2026-11-07 稳定性修复

- 设备重开失败不会复用已经释放的旧录音器；稳定采集后恢复连续失败预算。
- Start/Stop/Release 异常时完成必要清理，并保留原始异常供重试或诊断。
- 音频线程记录完整 traceback；停止和窗口长时间未更新都有明确状态。
- 监测代次隔离旧结果；停止后不发布上一轮结果，队列有上限。
- 系统关闭请求与关闭按钮共用非模态二次确认，不抢游戏焦点；正常关机/注销放行。
- 公开源码入口采用独立的退出日志/硬退出助手，不依赖私有保护代码。
- 音频医生基础设施失败返回非 0，不误报为没有声卡。

公开测试覆盖 **11 套自测、25 个稳定性回归用例**（不包含私有授权/保护层测试）。
