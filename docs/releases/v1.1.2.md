## 修复内容

- 设备重开失败不复用已释放的录音器；稳定采集后恢复连续重试预算。
- 录音 Start / Stop / Release 失败时完成清理并保留原始异常。
- 完整音频 traceback、停止与窗口过期状态；重新开始可受控重建。
- 监测代次隔离旧结果，结果队列有上限。
- 非模态关闭确认：2.5 秒内再次关闭才退出，不抢游戏焦点；正常关机/注销放行。
- 受控硬退出及线程超时取证；音频医生基础设施异常不误报成功。
- Win64 CONTEXT 完整缓冲/对齐及 MMCSS API 类型声明。

ZIP 重新解压的 CRC、内容哈希、版本、自检和缺失授权拒绝也通过；详细记录见发布页。

**未做 Authenticode 代码签名**，可能出现未知发布者或 SmartScreen 提示；校验值不是代码签名。
