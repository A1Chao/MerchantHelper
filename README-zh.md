# 行商助手（MerchantHelper）

> 《暗区突围：无限》「战地行商」玩法的**外部感知**辅助工具
> 作者：**烟火**

**按住左键拖动物品**时，它同时"听"和"看"，把可能的物品候选与参考价值显示在一个独立悬浮小窗里。

---

## 一、这是什么

| | 做什么 |
| --- | --- |
| **听** | 采集系统回环音频（WASAPI loopback），与内置音效模板比对，给出音效匹配的候选物品 |
| **看**（官方版） | 识别光标下物品的**占格与朝向**，用来给候选排序与筛选 |
| **显示** | 独立置顶悬浮小窗：格数 / 朝向 / 来源 + 候选列表（品质、类别、参考价值） |

**原理与 OBS 之类的录制/显示软件别无二致**：都是对屏幕画面与系统音频做**外部采集**再识别。
本工具**纯只读**：

- ❌ 不读游戏内存　❌ 不注入进程　❌ 不修改游戏文件　❌ 不解包游戏资源
- ❌ 不模拟键鼠（无 SendInput / mouse_event / keybd_event）、不自动点击、不自动购买
- ❌ 不联网、不自学习、不热更新
- ✅ 只用只读 API 读按键与光标（`GetAsyncKeyState` / `GetCursorPos`）
- ✅ UI 是独立悬浮窗，不覆盖游戏画面、不抢焦点

理论上没有任何风险，但请自行判断后使用。

## 二、⚠️ 本仓库是「开源版」

本仓库是**半开源版**，包含：音频识别（`recognition.py`）、候选筛选（`candidates.py`）、
界面（`ui.py`）、录音与降噪、集成层（`main.py`）。

**不包含**：占格识别（视觉核心 `vision.py`）—— 仓库里的 `vision.py` 只是占位 stub。

| 能力 | 开源版（本仓库） | 官方版（Releases 的 exe） |
| --- | :---: | :---: |
| 音频识别 | ✅ | ✅ |
| 候选筛选 | ✅ | ✅ |
| 面板界面 | ✅ | ✅ |
| **占格 / 朝向识别** | ❌（显示 `?格`） | ✅ |

→ **想要完整功能，请用 Releases 里的官方 exe。**

## 三、运行（源码）

### 环境

- Windows 10 / 11
- Python **3.12**（开发环境 3.12.5；其他版本未验证）
- `pip install -r requirements.txt`
- 音频设备访问使用仓库内置的 `deps/`（comtypes、soundcard），无需额外安装

### 快速开始

```bat
python main.py --list-devices          :: 列出播放设备
python main.py                          :: 自动选择默认播放设备
python main.py --device "扬声器 (2- Realtek(R) Audio)"
python main.py --no-vision              :: 只做音频识别（开源版的实际能力）
python main.py --pitch 85               :: 手动指定格宽（需配合视觉核心）
```

### 用法

1. 启动后按 **F8** 开始监测（面板显示"监测中"）
2. 游戏内**按住左键拖动**物品 —— **单击不会出声，必须拖动**
3. 看面板：格数 / 朝向 / 来源 + 候选列表
4. 再按 **F8** 停止

### ⚠️ 必须用管理员权限运行

实测目标游戏以更高权限运行，**普通权限下本工具读不到按键**（表现为"毫无反应"）。
请**右键 → 以管理员身份运行**。

## 五、常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 拖动物品毫无反应 | 没有用管理员权限（见上） |
| 面板没有候选 | 单击不出声，必须**拖动**；或设备选错（先 `--list-devices`） |
| 格数显示 `?格` | 开源版没有视觉核心；请用官方 exe |
| 面板挡视线 | 面板是可拖动的独立小窗，拖到合适位置即可 |
